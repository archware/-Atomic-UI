# Índice de artefactos de diagnóstico históricos

Los archivos siguientes son capturas generadas y no describen el estado actual
del proyecto:

| Artefacto | Sustituto vigente |
|---|---|
| `eslint-errors.txt`, `eslint-warnings.txt`, `fresh-lint-report.txt` | `npm run lint` |
| `build-angular21.log` | `npm run build` con Angular 22.1 y Atomic UI 5.8.4 |
| `ng-serve.err.log`, `ng-serve.out.log` | `npm start` en una sesión nueva |
| `lint-report.json` | `npm run lint` |

Las capturas se preservan como evidencia y no deben usarse para declarar una
compuerta verde o un error vigente. La autoridad es la ejecución reproducible
en el checkout actual.
