## Qué se esperaba

Fuente Atomic con estilos externos y propagación verificable que preserve el
diseño, conforme a la doctrina maestra, apartado 3, y política Atomic-first.

## Qué se observó

La auditoría previa detectó siete bindings de estilo en cinco componentes:
floating-textarea, row, comparison-chart, summary-list y sidebar. La instalación
de gobierno rechaza `ventas-cxc` por estar debajo de una raíz Git compartida.
El generador compone modal-catalog sin la plantilla PaginaCrud existente.

## Evidencia reproducible de la línea base

Desde Atomic, `npm run check:external-styles` devolvió código 1 con los siete
bindings; `npm run governance:install -- C:/Users/cotaha/source/repos/ventas-cxc
--ui-root=src/app/shared/ui --audit-only` devolvió código 1:

```text
La ruta consumidora debe ser exactamente la raíz de su repositorio Git.
```

## Corrección mínima que preserva la doctrina

Usar clases para estados y la directiva de variables CSS existente para datos
realmente dinámicos; la propiedad visual queda en la hoja externa. Catalogar
las capacidades de presentación. Preparar soporte de proyecto dentro de Git
sin escribir en su raíz compartida. Validar antes de propagar; el estado final
y las compuertas se registran en la evidencia de esta asignación.

## Lo que NO se debe hacer

No eliminar diseño útil, relajar gates, falsear manifiestos, copiar pruebas sobre
las del consumidor ni ejecutar el instalador en la raíz compartida como atajo.
No confirmar ni publicar: sigue vigente el congelamiento del repositorio.

## Escalado

La propagación final requiere revisión del Guardián y referencia limpia elegible.
No se cierra esta desviación por documentar la restricción ni por un build verde.

No se amplía el cambio a autenticación. Permanecen pendientes generador,
validación visual completa e integración CI; ver la evidencia de la asignación.
