# Roadmaps de mejora

Esta carpeta contiene los roadmaps de mejora del proyecto. Cada roadmap documenta las tareas planificadas antes de iniciar una mejora o refactorizacion.

## Convenciones
- Formato de nombre: `ROADMAP_YYYYMMDD_descripcion_breve.md`
- Cada tarea debe usar checklists: `[ ]` pendiente, `[x]` completada.
- Al finalizar todas las tareas, el roadmap queda como historial auditable.
- Obligatorio actualizar `CHANGELOG.md` y `LESSONS_LEARNED.md` al cerrar un roadmap.
